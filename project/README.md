# Project A Notebook

This directory contains the CL677 Project A deliverable as a marimo notebook in
`notebook.py`, together with supporting figure assets and source documents under
`docs/`.

Project scope:

- reproduce Figure 1 and Figure 6 from Filip, Javeed, and Trefethen,
  *Smooth Random Functions, Random ODEs, and Gaussian Processes*
- verify that smooth random forcing for the geometric random walk approaches the
  Stratonovich limit
- provide one notebook that works as an interactive marimo notebook and as a
  slide-friendly presentation source

Included source materials:

- `docs/random.pdf` as the original paper source
- `docs/random_ocr.pdf/` as OCR-extracted pages and figure assets
- `docs/ground_truth/` as the staged figure panels used for direct comparison

Notebook tooling used in this project:

- `marimo-pair`
- `Codex`
- `OpenCode`
